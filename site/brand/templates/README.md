# Canva templates (optional)

Design backgrounds in Canva with the text areas left empty, export as PNG, and drop them here.
The renderer uses them instead of its built-in backgrounds and writes the copy on top.

| File | Size | Used for |
|---|---|---|
| `cover.png` | 1080×1350 | carousel slide 1 (dark; text is white/yellow, top-left; keep the bottom 200px white for the logo band) |
| `content.png` | 1080×1350 | carousel slides 2–5 (light; text is navy, top-left, logo bottom-left) |
| `cta.png` | 1080×1350 | last carousel slide (light; logo centered near the top, text below) |
| `onepager.png` | 1080×1350 | evening one-pager (dark; keep the bottom 200px white) |
| `story.png` | 1080×1920 | noon Story (dark; keep the bottom 260px white) |
